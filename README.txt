STRATX PREMIUM SPORTS ANALYTICS

Installation : exécuter schema.sql dans Supabase SQL Editor puis héberger les trois fichiers web en HTTPS. Tester création de compte, connexion et sauvegarde.

Cette version fournit une interface premium en cases, analyses sportives, communauté, profil et observations historiques Aviator/JetX/CosmoX. Les cotes en direct nécessitent un fournisseur de données autorisé; aucune cote n'est inventée et aucun ticket de pari n'est inclus. Les résultats passés des jeux aléatoires ne prédisent pas les résultats futurs. Le code n'a pas été déployé/testé en direct sur le projet Supabase. Ne jamais exposer une clé service_role dans le navigateur.
